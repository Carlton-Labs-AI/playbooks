# playbooks

A one-person software business, built and sold with AI agents. What actually works, with playbooks.

Each playbook is a practice run before it is written up: when to use it, the steps, and the pitfalls. Coding with Claude Code, Cursor, Codex and other AI coding agents comes first; product design, go-to-market and marketing enter as they are actually done. Lab notes cover the experiments still in flight, dead ends included.

The essays that go with these pages are at https://carltonlabs.substack.com.

## Skills

- [whats-next](skills/whats-next/): ask Claude Code "where was I?" and get the next step, with the evidence behind it.
