# whats-next

A Claude Code skill that answers "what's next?" or "where was I?" from the project's actual state: git, open pull requests, plans, issues, dated milestones and your own hand-off notes. It recommends one next step and up to two alternatives, each with the evidence behind it, and never changes anything.

Written for Claude Code with the compound-engineering plugin; the checks work in any git repo.

## Install

Copy `SKILL.md` to `.claude/skills/whats-next/SKILL.md` in your project, or to `~/.claude/skills/whats-next/SKILL.md` to use it everywhere. Then ask Claude Code "what's next?"
